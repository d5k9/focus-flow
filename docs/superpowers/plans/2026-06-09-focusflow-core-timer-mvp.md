# FocusFlow — Core Timer MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship the v1 Core Timer MVP of FocusFlow — a native macOS menu-bar Pomodoro app with a glassmorphic popover, live `MM:SS` menu-bar countdown, preferences, onboarding, and completion notifications/chimes.

**Architecture:** Hybrid layout. A pure, headless **`FocusFlowKit` Swift Package** holds the Domain (`PomodoroEngine`), Services protocols + clock/ticker, `SettingsStore`, and the `TimerViewModel` — all unit-tested with fast `swift test` and a fake clock. A **thin Xcode app target** (generated declaratively from `project.yml` via XcodeGen) holds the SwiftUI views, design system, concrete `UserNotifications`/`AVFoundation`/`AppKit` services, and the `MenuBarExtra` app shell. Each layer depends only downward; the domain has zero Apple-framework dependencies.

**Tech Stack:** Swift 6 toolchain (Swift 5 language mode for v1 to keep concurrency relaxed), SwiftUI + AppKit interop, `MenuBarExtra(.window)`, Observation (`@Observable`), `UserDefaults`, Swift Testing (`import Testing`), XcodeGen, macOS 26 deployment target (Liquid Glass `glassEffect`, with `NSVisualEffectView` fallback).

**Design source:** Stitch theme *Ventura Focus* (`projects/14492833859784039326`). Tokens are transcribed verbatim into `DesignTokens.swift` in Task 9.

import Foundation

/// Cycle configuration: phase durations and how often a long break occurs.
public struct PomodoroSettings: Equatable, Sendable, Codable {
    public var focusDuration: TimeInterval
    public var shortBreakDuration: TimeInterval
    public var longBreakDuration: TimeInterval
    /// A long break replaces the short break after every `longBreakInterval`
    /// completed focus sessions. Always >= 1.
    public var longBreakInterval: Int

    public init(
        focusDuration: TimeInterval = 25 * 60,
        shortBreakDuration: TimeInterval = 5 * 60,
        longBreakDuration: TimeInterval = 15 * 60,
        longBreakInterval: Int = 4
    ) {
        self.focusDuration = focusDuration
        self.shortBreakDuration = shortBreakDuration
        self.longBreakDuration = longBreakDuration
        self.longBreakInterval = max(1, longBreakInterval)
    }

    public func duration(for phase: PomodoroPhase) -> TimeInterval {
        switch phase {
        case .focus: return focusDuration
        case .shortBreak: return shortBreakDuration
        case .longBreak: return longBreakDuration
        }
    }

    public static let `default` = PomodoroSettings()
}
```

## Task 4: Domain — `PomodoroEngine` (the heart)

The engine is a pure state machine over phases. It owns the current phase and the completed-focus count, and exposes `complete` / `skip` / `reset`. It has **no clock** — timing is the view model's job.

**Transition contract (tested exhaustively below):**
- `complete()` on a focus phase credits one focus session, then advances to a **long break** when the new count is a multiple of `longBreakInterval`, otherwise a **short break**.
- `complete()` / `skip()` on any break advances to **focus**.
- `skip()` on a focus phase **does not** credit the session, so it always advances to a **short break**.
- `reset()` returns to a fresh first focus with count 0.

import Foundation

/// Pure value-type Pomodoro state machine. Owns the current phase and the
/// completed-focus count, and computes the next phase. It is *driven* — it
/// has no clock and no notion of elapsed time. See the transition contract
/// in the plan / tests for exact semantics.
public struct PomodoroEngine: Equatable, Sendable {
    public private(set) var currentPhase: PomodoroPhase
    public private(set) var completedFocusCount: Int
    public var settings: PomodoroSettings

    public init(settings: PomodoroSettings = .default) {
        self.settings = settings
        self.currentPhase = .focus
        self.completedFocusCount = 0
    }

    /// Duration of the phase currently in progress, per the settings.
    public var currentPhaseDuration: TimeInterval {
        settings.duration(for: currentPhase)
    }

    /// Marks the current phase finished and advances. A completed focus phase
    /// is credited toward the long-break interval.
    public mutating func complete() { advance(creditFocus: true) }

    /// Skips the current phase. A skipped focus is never credited, so it
    /// always leads to a short break.
    public mutating func skip() { advance(creditFocus: false) }

    /// Returns to a fresh first focus phase and clears the counter.
    public mutating func reset() {
        currentPhase = .focus
        completedFocusCount = 0
    }

    private mutating func advance(creditFocus: Bool) {
        if currentPhase == .focus {
            if creditFocus { completedFocusCount += 1 }
            let dueLongBreak = creditFocus
                && completedFocusCount % settings.longBreakInterval == 0
            currentPhase = dueLongBreak ? .longBreak : .shortBreak
        } else {
            currentPhase = .focus
        }
    }
}
```

```swift
import Foundation

/// A periodic heartbeat. Implementations only fire `onTick`; remaining-time
/// math lives in the view model and is anchored to an absolute end-Date,
/// so missed/throttled ticks never cause drift.
public protocol TimerTicker: AnyObject {
    func start(onTick: @escaping () -> Void)
    func stop()
}

public final class DispatchSourceTimerTicker: TimerTicker {
    private var timer: DispatchSourceTimer?
    private let queue: DispatchQueue
    private let interval: TimeInterval
    private let leeway: DispatchTimeInterval

    public init(
        queue: DispatchQueue = .main,
        interval: TimeInterval = 1.0,
        leeway: DispatchTimeInterval = .milliseconds(100)
    ) {
        self.queue = queue
        self.interval = interval
        self.leeway = leeway
    }

    public func start(onTick: @escaping () -> Void) {
        stop()
        let t = DispatchSource.makeTimerSource(queue: queue)
        t.schedule(deadline: .now() + interval, repeating: interval, leeway: leeway)
        t.setEventHandler(handler: onTick)
        timer = t
        t.resume()
    }

    public func stop() {
        timer?.cancel()
        timer = nil
    }

    deinit { stop() }
}
```

```swift
import Foundation
import Observation

/// Owns the engine and ticker, and drives the timer. Anchors to an absolute
/// end-Date and recomputes remaining from the clock each tick, so it never
/// drifts across sleep/wake or timer throttling.
@MainActor
@Observable
public final class TimerViewModel {
    public private(set) var engine: PomodoroEngine
    public private(set) var isRunning = false
    public private(set) var remaining: TimeInterval

    @ObservationIgnored private let ticker: TimerTicker
    @ObservationIgnored private let clock: Clock
    @ObservationIgnored private let notifications: NotificationScheduling
    @ObservationIgnored private let sound: SoundPlaying
    @ObservationIgnored private var endDate: Date?

    public init(
        settings: PomodoroSettings = .default,
        ticker: TimerTicker,
        clock: Clock = SystemClock(),
        notifications: NotificationScheduling,
        sound: SoundPlaying
    ) {
        self.engine = PomodoroEngine(settings: settings)
        self.ticker = ticker
        self.clock = clock
        self.notifications = notifications
        self.sound = sound
        self.remaining = engine.currentPhaseDuration
    }

    // MARK: Derived state for views

    public var phase: PomodoroPhase { engine.currentPhase }
    public var completedFocusCount: Int { engine.completedFocusCount }

    public var displayTime: String {
        let total = max(0, Int(remaining.rounded(.up)))
        return String(format: "%02d:%02d", total / 60, total % 60)
    }

    public var progress: Double {
        let total = engine.currentPhaseDuration
        guard total > 0 else { return 0 }
        return min(1, max(0, 1 - remaining / total))
    }

    // MARK: Intents

    public func toggle() { isRunning ? pause() : start() }

    public func start() {
        guard !isRunning else { return }
        if remaining <= 0 { remaining = engine.currentPhaseDuration }
        endDate = clock.now.addingTimeInterval(remaining)
        isRunning = true
        ticker.start { [weak self] in
            Task { @MainActor in self?.tick() }
        }
    }

    public func pause() {
        guard isRunning else { return }
        tick()                 // capture latest remaining before freezing
        ticker.stop()
        endDate = nil
        isRunning = false
    }

    public func reset() {
        stopTimer()
        engine.reset()
        remaining = engine.currentPhaseDuration
    }

    public func skip() {
        stopTimer()
        engine.skip()
        remaining = engine.currentPhaseDuration
    }

    /// Recomputes remaining from the clock. Internal so tests drive it
    /// directly and deterministically (no async hop needed).
    func tick() {
        guard let endDate else { return }
        remaining = max(0, endDate.timeIntervalSince(clock.now))
        if remaining <= 0 { completePhase() }
    }

    // MARK: Private

    private func stopTimer() {
        ticker.stop()
        endDate = nil
        isRunning = false
    }

    private func completePhase() {
        stopTimer()
        let finished = engine.currentPhase
        sound.playCompletionChime()
        engine.complete()
        notifications.notifyPhaseComplete(finished: finished, next: engine.currentPhase)
        remaining = engine.currentPhaseDuration
    }
}
```

import UserNotifications
import FocusFlowKit

/// Posts desktop alerts via UNUserNotificationCenter. Honours the user's
/// "Desktop Alerts" preference and degrades silently (never crashes) when
/// authorization is denied — per the spec error-handling rules.
final class UserNotificationService: NotificationScheduling {
    private let isEnabled: () -> Bool

    init(isEnabled: @escaping () -> Bool) {
        self.isEnabled = isEnabled
    }

    func requestAuthorization() async -> Bool {
        do {
            return try await UNUserNotificationCenter.current()
                .requestAuthorization(options: [.alert, .sound])
        } catch {
            return false
        }
    }

    func notifyPhaseComplete(finished: PomodoroPhase, next: PomodoroPhase) {
        guard isEnabled() else { return }
        let content = UNMutableNotificationContent()
        content.title = "\(finished.title) complete"
        content.body = "Time for \(next.title)."
        let request = UNNotificationRequest(
            identifier: UUID().uuidString, content: content, trigger: nil)
        UNUserNotificationCenter.current().add(request)   // failures are ignored, not fatal
    }
}

/// Plays a completion chime. Honours "Sound Effects"; if the named sound is

final class SystemSoundService: SoundPlaying {
